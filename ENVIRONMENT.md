# Environment

## Supported development setup

- Node.js 24 or newer
- pnpm 11
- Expo SDK 57 / React Native 0.86
- Xcode 26+ and CocoaPods for iOS native builds
- Android Studio plus an Android SDK for Android native builds

Install JavaScript dependencies with `pnpm install`. The app uses Expo Router and can be opened from `pnpm start`; no `.env` file is required for the local MVP.

## Verified workspace

The implementation was built on macOS with Node 24.19.0, pnpm 11.19.0, Xcode 26.6, iOS Simulator 26.5, and an iPhone 17 Pro simulator. `pod install` and a normally signed Debug simulator build completed successfully.

The host did not contain an Android SDK/emulator, so Android native compilation and TalkBack were not run here. The Android Expo configuration, package identifier, permissions, adaptive icon, and platform-neutral application code are present; Android device certification remains release-device QA.

## Native regeneration

`ios/` was generated by Expo prebuild and has an installed Pods workspace. If native configuration changes, use:

```bash
pnpm exec expo prebuild --platform ios
cd ios && pod install
```

The repository contains `Gemfile.cocoapods` to pin a compatible CocoaPods toolchain when the system Ruby is old.

## Optional external services

Supabase is intentionally not configured. A future adapter must receive URL/keys through runtime configuration, enable RLS, and preserve local IDs and `brew_session_id` idempotency. OCR is currently a permission-aware image capture/gallery flow with verified manual fallback; adding an on-device OCR engine requires a separately selected native dependency, not a secret.
